# CS-370-M01-Current-Emerging-Trends-in-CS-2026

For this project, I built a pirate intelligent agent using deep Q learning. I was given starter code that already included the maze environment in TreasureMaze.py and the experience replay system in GameExperience.py. The notebook also had helper functions and a basic structure. My main job was to complete the qtrain() function and make the agent actually learn how to reach the treasure instead of just moving randomly.

What I added was the full training loop. I set it up so the agent starts in a random position, chooses actions, and learns from rewards and penalties. I used epsilon to control exploration and exploitation, stored past experiences in memory, and trained the neural network using batches of that data. I also tracked win rates and updated the target network during training to keep things stable. Before this, it was just a framework. After my part, the agent could actually improve over time.

Working on this changed how I see computer science. It is not just about writing code that runs. It is about building systems that can solve problems and sometimes even learn from experience. In this case, it was a maze, but the same idea applies to real situations like navigation systems, recommendation systems, or even healthcare tools. That is what makes this field important. The things we build can actually impact how people make decisions and how efficiently things get done.

When I approach problems now, I try to slow down and think through them instead of jumping straight into coding. I break the problem into smaller parts, figure out what each part needs, and then decide what tools or algorithms make sense. In this project, I had to understand reinforcement learning first, then figure out how to connect it to the neural network and training process. I also had to test things, fix errors, and adjust values when the results were not good. It showed me that problem solving is a process, not just a one time solution.

I also think more about responsibility now. Even though this project was just a game, the same kind of AI can be used in real systems. That means I need to think about fairness, bias, and privacy when building anything. If an AI system is trained on bad data, it can give bad or unfair results. Also, if it handles personal information, that data needs to be protected. As someone going into tech, I know I cannot just focus on making something work. I also have to think about how it affects people and if it is being used the right way.

This project helped me connect what I learned in class to something I could actually see working. Watching the agent improve over time made everything click more for me, especially how reinforcement learning works in practice.
